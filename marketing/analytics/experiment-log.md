# Experiment & A/B Test Log

## How to Use

1. Before testing: fill in hypothesis, variable, control, variant, metric
2. During test: run for minimum 2 weeks (4 data points per variant)
3. After test: record results, declare winner, extract learning
4. Apply: mark whether the learning was applied to future content
