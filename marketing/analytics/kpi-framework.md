## Content Performance KPIs

### Per-Piece Metrics
| Metric | Source | What It Tells You |
|--------|--------|-------------------|
| Views | IG Insights / TikTok Analytics | Reach — did people see it? |
| Watch time | Platform analytics | Hook quality — did they stay? |
| Completion rate | Platform analytics | Content quality — did they finish? |
| Likes | Platform | Passive approval |
| Comments | Platform | Active engagement |
| Shares | Platform | Virality — worth spreading |
| Saves | IG Insights | Value — worth revisiting |
| Profile visits | Platform | Interest in the brand |
| WA clicks | Link tracking | Conversion — action taken |

### Performance Tiers
| Tier | Views (vs average) | Engagement Rate | Action |
|------|--------------------|-----------------|--------|
| **Top performer** | >2x average | >5% | Analyze why, replicate format |
| **Strong** | 1.5x–2x average | >4% | Good — continue this approach |
| **Average** | 0.5x–1.5x average | 2–4% | Normal — no special action |
| **Underperformer** | <0.5x average | <2% | Diagnose, iterate, or retire format |
