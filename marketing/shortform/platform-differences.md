# Platform Differences: Instagram Reels vs TikTok — Star Laundry

## Why This File Matters

This is the most important reference for anyone creating or adapting content. Instagram Reels and TikTok look similar but behave very differently. Posting identical content to both platforms without adaptation will underperform on both. Every difference below includes specific Star Laundry examples.

---

## 1. Hook Style

### Instagram Reels: Visual-First Hook
Instagram users scroll a visual feed. The first frame must be visually compelling enough to stop the scroll. Text hooks are secondary.

**Star Laundry approach:**
- Open with a striking visual — a mountain of dirty clothes, a sparkling clean machine, steam rising from an iron
- Use the first 0.5s for a "pattern interrupt" image before any text appears
- Example: Open on a close-up of a perfectly folded white shirt with Star Laundry blue backdrop, then reveal the transformation

### TikTok: Text/Voice Hook
TikTok users respond to spoken or text-based hooks that create curiosity or tension. The visual supports the words, not the other way around.

**Star Laundry approach:**
- Start with a bold text overlay or voiceover: "Anak kos yang belum nyuci 2 minggu..." or "Ternyata salah cuci selama ini..."
- Hook must pose a question, create tension, or promise a reveal
- Example: Voiceover "Ini yang terjadi kalau kamu cuci baju warna sama putih..." while showing the washing machine

---

## 2. Pacing

### Instagram Reels: Slightly Polished
IG audiences tolerate (and prefer) a slightly more produced feel. Cuts every 2-3 seconds. Smooth transitions.

**Star Laundry approach:**
- Show the full wash cycle progression with clean cuts: load → wash → dry → fold → pack
- Use CapCut smooth zoom transitions between steps
- Hold satisfying shots (folding, ironing) for 2-3 seconds to let the visual breathe

### TikTok: Faster Cuts
TikTok rewards faster pacing. Cuts every 1-2 seconds. Jump cuts are normal and expected.

**Star Laundry approach:**
- Same wash cycle but with rapid jump cuts and beat-synced transitions
- Speed-ramp the washing machine spinning, quick cuts between dirty → clean
- Add zooms and shakes for energy on beat drops

---

## 3. Retention Structure

### Instagram Reels: Front-Loaded Value
IG's algorithm heavily weights the first 3 seconds. Front-load the payoff or the promise.

**Star Laundry approach:**
- Show the end result first (perfectly packed laundry), then show the process
- "Hasil akhir cuci setrika di Star Laundry" → then show the dirty pile → process → result
- Put the best visual in the first frame for Explore page thumbnails

### TikTok: Pattern Interrupts Throughout
TikTok measures watch-through rate. You need to maintain attention across the entire video with surprises, reveals, and pattern changes.

**Star Laundry approach:**
- At second 5: unexpected twist ("tapi tunggu, lihat ini...")
- At second 12: reveal or before/after comparison
- At second 20: final payoff + CTA
- Example: "POV cuci di Star Laundry" — interrupt at second 8 with staff doing something funny/unexpected

---

## 4. CTA Style

### Instagram Reels: Bio Link / DM
Instagram supports clickable bio links and DM-based CTAs. Direct users there.

**Star Laundry approach:**
- End card: "Klik link di bio buat order via WhatsApp!"
- Or: "DM 'HARGA' buat dapetin price list lengkap"
- Caption CTA: "Link WhatsApp di bio ya!"
- Use Instagram's DM automation if available

### TikTok: Comment / Bio
TikTok CTAs work best through comments and bio. No clickable links in captions.

**Star Laundry approach:**
- End card: "Comment 'MAU' buat info lengkap!"
- Or: "Cek bio buat WhatsApp kita!"
- Pin a comment with the WhatsApp number
- Respond to every "MAU" comment with WA link

## 5. Caption Usage

### Instagram Reels: Longer, Keyword-Rich
IG captions are searchable. Use them for SEO and detailed context.

**Star Laundry approach:**
- 100-200 words per caption
- Include keywords: "laundry Boyolali", "cuci setrika", "coin laundry", "laundry terdekat"
- Structure: Hook line → context → CTA → hashtags
- Example: "Pertama di Boyolali! Coin laundry self-service yang bisa kamu pakai 24 jam. Ga perlu antri, ga perlu ribet. Tinggal masukkin, tunggu, beres. Cocok buat kamu yang sibuk kerja atau kuliah. Coba sekarang, link WhatsApp di bio! #LaundryBoyolali #CoinLaundry #StarLaundry"

### TikTok: Short, Punchy
TikTok captions are secondary to the video. Keep them short and curiosity-driven.

**Star Laundry approach:**
- 1-2 lines maximum
- Pose a question or add intrigue: "Ternyata ini rahasia baju selalu wangi..."
- Or use it to add context the video doesn't: "Star Laundry Boyolali, pertama di kota!"
- Example: "Anak kos wajib tau ini. #LaundryBoyolali #AnakKos"

## 6. Content Discovery Behavior

### Instagram Reels: Explore Page + Hashtags + Following Feed
Content is discovered through Explore, hashtag searches, and the following feed. Hashtags matter for local discovery.

**Star Laundry approach:**
- Use 15-20 hashtags mixing local + niche:
  - Local: #Boyolali #BoyolaliHits #KulinerBoyolali (piggybacking local community)
  - Niche: #LaundryBoyolali #CoinLaundry #TipsLaundry #CuciSetrika
  - General: #LaundryLife #BajuBersih #RumahRapi
- Optimize for Explore by using trending audio and high-engagement hooks

### TikTok: FYP Algorithm
TikTok's For You Page algorithm distributes content based on engagement signals, not followers or hashtags primarily.

**Star Laundry approach:**
- Hashtags are less critical but still used: #LaundryBoyolali #AnakKos #TipsLaundry #FYP
- Focus effort on watch time and engagement instead of hashtag strategy
- Use 3-5 relevant hashtags maximum
- Create content that encourages comments ("Setuju ga?", "Tim cuci sendiri atau laundry?")

## 7. Trend Adaptation

### Instagram Reels: Trends Arrive Later
IG trends typically lag TikTok by 1-3 weeks. This gives you time to plan and polish.

**Star Laundry approach:**
- Monitor TikTok trends and prepare IG versions 1-2 weeks later
- Polish the execution since IG audiences expect slightly higher production
- Example: If a "POV" trend is hot on TikTok now, plan the IG version for next week with cleaner filming

### TikTok: Trend-First Culture
TikTok rewards early trend adoption. Speed matters more than polish.

**Star Laundry approach:**
- Jump on trending sounds/formats within 24-48 hours
- Adapt any trending format to laundry context immediately
- Example: Trending "Day in my life" format → "Day in the life of Star Laundry staff" posted same day
- Keep a TikTok trend watchlist, check daily

## 8. Editing Rhythm

### Instagram Reels: Cleaner Edits
IG Reels benefit from smoother transitions, consistent color grading, and a more "produced" feel.

**Star Laundry approach:**
- Use CapCut smooth transitions (dissolve, slide)
- Consistent color grading: bright, slightly warm, clean
- Text animations: fade in/out, not jarring
- Background music at consistent level
- Brand colors (Blue #2AADE0, Yellow #FBB818) in text overlays

### TikTok: Raw/Fast Cuts OK
TikTok audiences prefer authentic, raw content. Over-produced content can feel inauthentic.

**Star Laundry approach:**
- Jump cuts are fine and expected
- Handheld camera shake adds authenticity
- Quick zoom-ins for emphasis
- Text can appear/disappear quickly
- Green screen effect for "reacting to" content
- Speed ramps (2x-4x) for process shots

## 9. Storytelling Format

### Instagram Reels: Aspirational / Aesthetic
IG content should make the viewer aspire to the lifestyle or aesthetic you're presenting.

**Star Laundry approach:**
- Show the *result* and *experience*: perfectly folded clothes, clean modern outlet, satisfying organization
- Aesthetic shots of the outlet interior, blue lighting, clean machines
- "This is what modern laundry looks like" energy
- Example: Slow-mo of fresh laundry being packed with Star Laundry branded packaging, soft music

### TikTok: Relatable / POV
TikTok content should make viewers feel seen. Use POV, relatable scenarios, and humor.

**Star Laundry approach:**
- "POV: Kamu anak kos yang udah 2 minggu ga nyuci" — relatable struggle
- "POV: Nyokap suruh nyuci gordyn jelang Lebaran" — family relatability
- First-person perspective, talking to camera
- Humor and self-deprecation work well
- Example: Staff pretending to be overwhelmed by a huge laundry pile, then showing the machine handling it easily

## 10. Educational vs Promotional Balance

### Instagram Reels: 60% Educational, 40% Promotional
IG audiences tolerate slightly more promotional content if it's well-produced and provides value.

**Star Laundry approach:**
- 3 educational reels per week (laundry tips, fabric care, stain removal)
- 2 promotional reels per week (pricing, promos, facility showcase)
- Educational examples: "Cara hilangkan noda kunyit dari baju putih", "Kenapa baju kamu bau apek setelah dicuci"
- Promotional examples: "Promo cuci setrika Rp 7.000/kg minggu ini!", outlet tour

### TikTok: 70% Educational/Entertaining, 30% Promotional
TikTok's algorithm suppresses overtly promotional content. Lead with value.

**Star Laundry approach:**
- 5 educational/entertaining videos per week
- 2 promotional videos per week (disguised as tips or stories)
- Educational examples: "3 kesalahan nyuci yang bikin baju cepet rusak", "Ternyata ini bedanya deterjen cair vs bubuk"
- Promotional must be wrapped in value: "Ini alasan kenapa laundry profesional lebih bersih dari cuci sendiri" (educational but positions Star Laundry)

## 11. Audio Strategy

### Instagram Reels: Music-Focused
IG Reels heavily promote content using trending music. The audio track drives the edit.

**Star Laundry approach:**
- Use trending IG music from the Reels music library
- Edit cuts to the beat of the music
- Voiceover is secondary — use text overlays + music
- Save trending audio to use later
- Example: Satisfying folding montage set to a trending upbeat track

### TikTok: Original Audio + Trending Sounds
TikTok values original audio (voiceover, talking to camera) and trending sounds equally.

**Star Laundry approach:**
- Talk to camera for educational content — original audio performs well
- Use trending sounds for trend-based content
- Create original sounds that others might use: "Star Laundry jingle" or a catchy laundry tip
- Duet/stitch with relevant content using original voiceover
- Example: Owner explaining a laundry tip directly to camera with no music, just authentic talking

## 14. Cross-Posting Rules

### What to Keep the Same
- Core concept and message
- Key visuals and footage
- Brand elements (colors, logo placement)
- CTA destination (WhatsApp)
- Factual information

### What to Adapt

| Element | Instagram Adaptation | TikTok Adaptation |
|---------|---------------------|-------------------|
| Hook | Visual-first, strong opening frame | Text/voice hook in first 1 second |
| Pacing | 2-3 second cuts, smooth transitions | 1-2 second cuts, jump cuts OK |
| Caption | 100-200 words, keyword-rich, 15-20 hashtags | 1-2 lines, 3-5 hashtags |
| CTA | "Link di bio" / "DM kami" | "Comment MAU" / "Cek bio" |
| Audio | Trending IG music, beat-synced | Original voiceover or trending TikTok sound |
| Text overlay | Clean, branded fonts, minimal | Bold, attention-grabbing, more text on screen |
| Editing | Polished transitions, color graded | Raw OK, speed ramps, zoom effects |
| Thumbnail | Design a custom cover image | First frame IS the hook |

### Cross-Post Workflow

1. Film the core content once
2. Edit the TikTok version first (faster, rawer — this is the base)
3. Re-edit for Instagram (polish transitions, adjust pacing, add cover image)
4. Write platform-specific captions
5. Schedule at platform-specific optimal times
6. Never post to both platforms at the exact same time — stagger by 2-4 hours minimum
