# Short-Form Content System — Star Laundry Boyolali

## Overview

This is Star Laundry's short-form video content system. It powers all reel-based content across **Instagram Reels** and **TikTok** — our two primary platforms for awareness, engagement, and driving WhatsApp inquiries.

Short-form video is our highest-leverage content format. It costs nothing but time, can be filmed entirely on a phone (HP) in our outlet, and reaches audiences we cannot access through paid ads alone.

## How Reel-Based Content Works

Every piece of short-form content follows a unified pipeline:

```
Idea → Brief → Script → Film → Edit → Adapt → Publish → Analyze
```

1. **Idea** — Logged in the idea bank using `templates/idea-template.md`
2. **Brief** — Developed into a short-form brief using `templates/brief-template.md`
3. **Script** — Written with hook, body, CTA structure (see `../workflows/`)
4. **Film** — Shot on HP in-outlet using `../assets/shot-list-template.md`
5. **Edit** — Cut in CapCut following `../assets/editing-guidelines.md`
6. **Adapt** — Platform-specific tweaks per `platform-differences.md`
7. **Publish** — Scheduled per `../calendar/` posting calendar
8. **Analyze** — Reviewed weekly using `../analytics/` dashboards

## Unified Workflow, Platform-Specific Output

We shoot **one core video** per concept, then adapt it for each platform:

- **Core video** — Filmed once, with the best hook and cleanest structure
- **Instagram Reels version** — Slightly polished edit, keyword-rich caption, music-forward audio, CTA to DM/bio link
- **TikTok version** — Faster cuts, text overlay hooks, trending sound where relevant, CTA to comment/bio

The key rule: **film once, edit twice**. Never post identical content to both platforms without adaptation. See `platform-differences.md` for the full adaptation checklist.

## Content Cadence

| Platform | Target | Content Mix |
|----------|--------|-------------|
| Instagram Reels | 4-5 reels/week | 60% educational, 40% promotional |
| TikTok | 5-7 videos/week | 70% educational/entertaining, 30% promotional |

## Quick Start for Content Team

1. Check `content-series.md` for this week's recurring series
2. Pull 2-3 ideas from the idea bank or `content-pillars.md`
3. Fill out a brief using `templates/brief-template.md`
4. Write the script (hook, body, CTA — max 60 seconds)
5. Film in-outlet using natural light + outlet lighting
6. Edit in CapCut with brand colors (Blue #2AADE0, Yellow #FBB818)
7. Adapt for each platform per `platform-differences.md`
8. Schedule and publish
