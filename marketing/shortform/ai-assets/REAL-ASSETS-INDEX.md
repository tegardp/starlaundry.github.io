## CapCut Tips for Real Assets

### Photos → Video (Ken Burns)
1. Import photo → place on 9:16 timeline
2. Add keyframe at start: slightly zoomed out
3. Add keyframe at end: zoomed in on subject
4. Duration: 3-5 seconds per photo
5. Apply "Smooth" ease for professional feel

### Video Clips
1. Import → trim to best 3-5 second segment
2. Apply speed curve for dramatic effect (slow → normal)
3. Use CapCut "Enhance" for brightness/color consistency
4. Add auto-captions if there's audio

### Transitions Between Real Assets
- Photo → Video: Use "Fade" or "Slide" (0.3-0.5s)
- Photo → Photo: Use "Zoom" transition
- Beat change: Use "Flash" transition (0.2s) on beat drop

### Color Grading (Consistency)
Apply the same filter to ALL real assets so they look cohesive:
- CapCut filter: "Fresh" or "Clean" category
- Slight boost: brightness +10, contrast +5, saturation +10
- Temperature: slightly cool (matches blue brand color)
