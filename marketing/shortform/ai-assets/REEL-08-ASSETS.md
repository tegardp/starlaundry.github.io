## A. Scene-by-Scene Storyboard

### Scene 1: HOOK (0-5s)
- **Duration:** 5 seconds
- **Visual:** Illustrated Star Laundry storefront with sunrise colors. Animated question marks floating around. Flat design style with blue (#2AADE0) and yellow (#FBB818) palette
- **Text Overlay:** "Pernah penasaran apa yang terjadi di laundry dari pagi sampai malam?"
- **Voiceover:** "Pernah penasaran apa aja yang terjadi di laundry dari pagi sampai malam?"
- **Transition:** Clock wipe (rotating clock hand)

### Scene 2: PAGI 07:00 (5-15s)
- **Duration:** 10 seconds
- **Visual:** Illustrated scene of a laundry shop opening. Character unlocking door, turning on lights, checking washing machines. Warm morning light colors. Clock graphic showing 07:00 in top corner. Flat illustration with soft shadows
- **Text Overlay:** "PAGI 07:00 - Buka toko, cek mesin, siap melayani!"
- **Voiceover:** "Pagi jam tujuh. Buka toko, cek semua mesin, dan siap menyambut pelanggan pertama!"
- **Transition:** Slide right with clock hand spinning

### Scene 3: SIANG 12:00 (15-25s)
- **Duration:** 10 seconds
- **Visual:** Busy illustrated laundry scene. Multiple washing machines spinning (animated circles), character ironing clothes, another folding neatly. Steam wisps rising. Clock shows 12:00. Bright, energetic colors
- **Text Overlay:** "SIANG 12:00 - Mesin full! Setrika, lipat, rapiin"
- **Voiceover:** "Siang jam dua belas. Mesin jalan semua! Setrika, lipat, rapiin satu per satu dengan teliti."
- **Transition:** Slide right with clock hand spinning

### Scene 4: SORE 17:00 (25-35s)
- **Duration:** 10 seconds
- **Visual:** Illustrated customers picking up neatly packaged laundry. Happy face expressions, small heart icons floating. Warm golden afternoon light. Clock shows 17:00. Shopping bag with Star Laundry logo
- **Text Overlay:** "SORE 17:00 - Pelanggan jemput cucian, senyum puas!"
- **Voiceover:** "Sore jam lima. Pelanggan mulai jemput cucian mereka. Bersih, wangi, rapi! Senyum puas, itu yang bikin semangat."
- **Transition:** Slide right with clock hand spinning

### Scene 5: MALAM 21:00 (35-42s)
- **Duration:** 7 seconds
- **Visual:** Illustrated closing scene. Character turning off lights, counter showing "87 kg cucian beres hari ini!" in a fun scoreboard graphic. Moon and stars outside window. Cozy night colors with blue tones
- **Text Overlay:** "MALAM 21:00 - Tutup toko. Hari ini 87kg cucian beres!"
- **Voiceover:** "Malam jam sembilan. Tutup toko. Hari ini delapan puluh tujuh kilo cucian beres!"
- **Transition:** Fade to dark

### Scene 6: CTA (42-45s)
- **Duration:** 3 seconds
- **Visual:** Star Laundry logo on blue background, illustrated sunrise peeking in from bottom. "Besok giliran cucian kamu ya!" text. WhatsApp number
- **Text Overlay:** "Besok giliran cucian kamu ya! WA 0822-2567-2756"
- **Voiceover:** "Besok giliran cucian kamu ya!"
- **Transition:** Fade out

## F. CapCut Assembly Instructions

### Step 1: Project Setup
1. Open CapCut, create new project, set to 9:16 (1080x1920)
2. Set project duration to 45 seconds

### Step 2: Import Assets
1. Import all 6 illustrated images from Section B
2. Import video/animation clips from Section C (if generated)
3. Import voiceover audio file
4. Search and add background music using terms in Section E

### Step 3: Timeline Assembly
1. **0-5s:** Place Image 1 (storefront sunrise). Add slow zoom-in animation using CapCut keyframes. Add text "Pernah penasaran..." in white handwritten-style font
2. **5-15s:** Place Image 2 (morning opening). Add subtle pan animation (left to right). Add timestamp graphic "PAGI 07:00" in top-left corner with blue background pill shape
3. **15-25s:** Place Image 3 (midday busy). Overlay Motion Scene 1 (washing machine spin) if available. Add "SIANG 12:00" timestamp. Add subtle zoom animation
4. **25-35s:** Place Image 4 (afternoon pickup). Overlay Motion Scene 3 (floating hearts). Add "SORE 17:00" timestamp. Slow pan animation
5. **35-42s:** Place Image 5 (night closing). Add slow zoom-out. Add "MALAM 21:00" timestamp. Animate the "87kg" number with a counting-up effect if possible
6. **42-45s:** Place Image 6 (CTA). Static with gentle pulse on the WhatsApp number

### Step 4: Time Stamp Graphics
1. Create consistent timestamp design: rounded rectangle, blue (#2AADE0) background, white bold text
2. Position in top-left corner for all four time scenes
3. Format: "PAGI 07:00" / "SIANG 12:00" / "SORE 17:00" / "MALAM 21:00"
4. Add pop-in animation when each timestamp appears

### Step 5: Clock Transition Effect
1. Between each time scene, add a brief (0.5s) clock wipe transition
2. If clock animation from Section C is available, overlay it during transitions
3. Alternative: Use CapCut's built-in "Clock Wipe" or "Rotate" transition

### Step 6: Text Overlays
1. Use a rounded, friendly font (Nunito, Quicksand, or similar)
2. Primary text: White with subtle shadow
3. Timestamp text: White on blue pill-shaped background
4. Keep text in lower-third safe zone (except timestamps)
5. Add "Pop" animation for text appearing

### Step 7: Audio
1. Place voiceover on audio track 1, align with each scene
2. Place background music on audio track 2
3. Set music volume to 25-30%
4. Add gentle fade-in (1s) at start
5. During the night scene (35-42s), slightly lower music volume for emotional effect
6. Fade out music over last 2 seconds

### Step 8: Final Touches
1. Add consistent blue (#2AADE0) thin border frame around entire video (optional, adds to the illustrated feel)
2. Add Star Laundry small logo watermark in top-right corner
3. Preview full reel and check pacing against voiceover
4. Export at 1080x1920, 30fps, high quality

## Style Reference Notes
This reel uses FLAT ILLUSTRATION style intentionally. Do NOT attempt to make it look like real filmed footage. The illustrated approach:
- Avoids uncanny valley of AI-generated "real" people
- Creates a unique, memorable visual identity
- Is consistent and controllable across all scenes
- Feels warm and approachable
- Stands out from typical laundry content
