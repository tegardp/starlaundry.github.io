# Workflow: Scriptwriting (Scriptwriter-Centric)

## Trigger
Approved content concept + hook delivered from Short-Form Content agent

## Required Inputs
- Content brief with approved concept
- 3 hook variations (text + spoken word)
- Target platform (IG Reels, TikTok, or both)
- Target duration (15s, 30s, 45s, or 60s)
- Content pillar and audience segment
- Key message and CTA requirement
- Brand tone of voice reference
- Performance insights on hook/format performance (if available)

## Steps

| # | Step | Owner Agent | Detail |
|---|------|-------------|--------|
| 1 | Receive brief + hooks | **Scriptwriter** | Read concept, hooks, and any reference material |
| 2 | Research angle and format | **Scriptwriter** | Check trending formats on target platform. Identify similar successful content. |
| 3 | Write full script | **Scriptwriter** | Scene-by-scene breakdown with timing, VO/dialogue, on-screen text, B-roll/action notes |
| 4 | Write primary hook (first 3 seconds) | **Scriptwriter** | Expand the selected hook into exact talent action + VO + text overlay |
| 5 | Write 2 alternative openings | **Scriptwriter** | Genuinely different hooks (not word swaps) — different visual, different angle |
| 6 | Write CTA section (last 3–5 seconds) | **Scriptwriter** | Natural CTA driving to WhatsApp — talent VO + text overlay |
| 7 | Create shortened 15-second version | **Scriptwriter** | Keep: hook + core message + CTA. Cut: setup/context beats. |
| 8 | Add talent recording notes | **Scriptwriter** | What talent needs to know: energy level, pace, gestures, expressions, outfit |
| 9 | Add recording checklist | **Scriptwriter** | Props, location in outlet, setup, estimated takes, total filming time |
| 10 | Submit for review | **Scriptwriter** → **Reviewer** | Complete script package |
| 11 | Review script | **Reviewer** | Brand voice, pricing accuracy, filmability, hook quality, CTA clarity |
| 12 | Revise if needed | **Scriptwriter** | Address specific Reviewer feedback |
| 13 | Handoff | **Scriptwriter** → **Copywriter** + **Creative Director** | Approved script goes to Copywriter for caption and Creative Director for shot list |

## Review Gate

The Reviewer checks:
- [ ] Hook stops scrolling in 3 seconds
- [ ] Script is in casual Indonesian (no "Anda", no formal language)
- [ ] CTA is present and drives to WhatsApp
- [ ] Pricing/promo terms are accurate
- [ ] Scene beats are visual (not just voiceover)
- [ ] Alternative hooks are genuinely different approaches
- [ ] 15-second version retains core message
- [ ] Filmable with phone in outlet by 1–2 people
- [ ] Recording notes are complete enough to film without questions

## Completion Criteria

- Full script with all sections filled
- 3 hook variations (genuinely different)
- 15-second shortened version
- Recording notes and checklist complete
- Reviewer approved
- Handed off to Copywriter and Creative Director

## Handoff Map

```
Short-Form Content → [concept + hooks] → SCRIPTWRITER → [approved script] → Copywriter (caption)
                                                                          → Creative Director (shot list)
                                                                          → Reviewer (quality gate)
```
