# Workflow: Short-Form Content Creation (Single Piece)

## Trigger
Content brief approved during weekly batch planning

## Required Inputs
- Approved content brief (concept, pillar, platform, audience, key message)
- Content pillar guidelines
- Platform difference guidance (`shortform/platform-differences.md`)
- Brand tone of voice
- Previous performance insights on similar content

## Steps

| # | Step | Owner Agent | Input | Output |
|---|------|-------------|-------|--------|
| 1 | Develop concept into detailed brief | **Short-Form Content** | Calendar concept | Detailed brief: angle, visual approach, reference |
| 2 | Create 3 hook variations | **Short-Form Content** | Detailed brief | 3 distinct hooks (text + spoken) with platform notes |
| 3 | Select primary hook | **Short-Form Content** + **Orchestrator** | 3 hooks + performance data on hook types | Primary hook selected, alts kept for testing |
| 4 | Write full script | **Scriptwriter** | Brief + primary hook + 2 alt hooks | Full script: beats, VO, text overlays, B-roll, CTA |
| 5 | Create shortened 15-sec version | **Scriptwriter** | Full script | Condensed script retaining hook + core message + CTA |
| 6 | Write caption + CTA | **Copywriter** | Approved script | IG caption + TikTok caption + hashtags |
| 7 | Create shot list + editing notes | **Creative Director** | Approved script | Shot-by-shot breakdown + filming + editing direction |
| 8 | Review all deliverables | **Reviewer** | Script, caption, shot list | Approval or specific revision requests |
| 9 | Revisions (if needed) | **Originating agents** | Reviewer feedback | Revised deliverables |
| 10 | Add platform adaptation notes | **Short-Form Content** | Approved script + shot list | What to change for IG Reels vs TikTok version |
| 11 | Compile final filming brief | **Orchestrator** | All approved outputs | Single document: brief + script + caption + shot list + adaptation notes |

## Review Gates

- **Gate 1** (after step 3): Hook selection confirmed — does it pass the "3-second scroll stop" test?
- **Gate 2** (after step 8): Full review — brand fit, accuracy, filmability, platform requirements

## Required Outputs

- [ ] Content brief (detailed)
- [ ] 3 hook variations (1 primary + 2 alternatives)
- [ ] Full script with scene beats, timing, VO, text overlays, B-roll notes
- [ ] 15-second shortened version
- [ ] Talent recording notes
- [ ] Recording checklist (props, setup, preparation)
- [ ] Instagram caption + hashtags
- [ ] TikTok caption + hashtags
- [ ] Shot list with filming direction
- [ ] Editing notes (cuts, transitions, music, color)
- [ ] Platform adaptation notes (IG vs TikTok differences)
- [ ] Thumbnail/cover frame guidance

## Completion Criteria

- All deliverables approved by Reviewer
- Script is filmable by 1–2 people with phone in outlet
- CTA drives to WhatsApp
- Caption matches script message
- Shot list covers every script beat
- Platform adaptation notes are specific (not generic)

## Time Estimate
- Full workflow for 1 piece: 1–2 hours (agent work)
- In a weekly batch of 6 pieces: 4–6 hours total (parallelized)
