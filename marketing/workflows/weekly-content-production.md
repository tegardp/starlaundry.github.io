# Workflow: Weekly Content Batch Production

## Trigger
Every Monday morning (or Sunday evening for prep)

## Required Inputs
- Monthly content calendar (this week's planned concepts)
- Active campaign briefs
- Previous week's performance insights (from Analytics)
- Content pillar targets for the week
- Any pending content from last week
- Agent memory files (each agent reads their own + `memory/shared.md` before starting)

## Steps

| # | Step | Owner Agent | Input | Output | Deadline |
|---|------|-------------|-------|--------|----------|
| 0 | Load memory | **All agents** | `memory/shared.md` + agent-specific memory file | Context for this week's work | Monday AM |
| 1 | Review this week's calendar | **Orchestrator** | Monthly calendar, pending items, memory context | Confirmed list of 5–7 pieces for the week | Monday AM |
| 2 | Batch ideate concepts + hooks | **Short-Form Content** | Calendar, campaign briefs, pillar targets | 5–7 content briefs with 3 hooks each | Monday |
| 3 | Write scripts for video content | **Scriptwriter** | Content briefs + hooks | 5–7 scripts with scene beats, alt hooks, 15s versions | Tuesday |
| 4 | Write captions + WA broadcasts | **Copywriter** | Approved scripts, WA schedule | 5–7 captions + 2 WA broadcasts + 1 GMaps post | Tuesday–Wednesday |
| 5 | Create shot lists + creative notes | **Creative Director** | Approved scripts | 5–7 shot lists with filming/editing direction | Wednesday |
| 6 | Review all outputs | **Reviewer** | Scripts, captions, shot lists | Approval or revision requests | Thursday AM |
| 7 | Revisions (if needed) | **Originating agent** | Reviewer feedback | Revised deliverables | Thursday |
| 8 | Compile final content pack | **Orchestrator** | All approved outputs | Weekly content pack: filming-ready briefs | Thursday PM |
| 9 | Update memory | **All agents** | Observations from this batch | New learnings appended to memory files | Thursday PM |

## Weekly Content Pack (output)

For each content piece, the pack includes:
```
CONTENT PIECE #[ID]
- Brief: concept, pillar, platform, target segment
- Script: hook + scene beats + CTA + 15s version + recording notes
- Caption: IG caption + TikTok caption
- Shot list: per-beat shots + filming/editing notes
- Platform adaptation notes (if cross-posting)
```

Plus:
- 2 WA broadcast messages (Monday + Friday)
- 1 Google Maps post

## Review Gates

- **Gate 1** (after step 2): Orchestrator confirms concepts match calendar and pillar targets
- **Gate 2** (after step 6): Reviewer checks all deliverables for quality, accuracy, brand fit

## Completion Criteria

- All 5–7 content pieces have complete briefs (script + caption + shot list)
- WA broadcasts written and approved
- All pricing/promo terms verified
- Content pack compiled and ready for filming
- Filming schedule set (when, where, who)

## Filming & Posting Schedule

| Day | Activity |
|-----|----------|
| Monday | Batch planning + ideation + WA broadcast |
| Tuesday | Scriptwriting + caption writing |
| Wednesday | Shot lists + creative direction |
| Thursday | Review + revisions + compile pack |
| Friday | Filming batch (aim for 3–4 pieces in one session) + WA broadcast |
| Saturday | Edit + post content |
| Sunday | Edit remaining + light posting + prep for next week |

## Notes

- Batch filming saves time: film 3–4 pieces in one session on Friday
- Always film more hooks than you need — test different openers
- If a piece doesn't pass review, deprioritize rather than rushing a weak piece
- Keep a 2-piece buffer of evergreen content for emergencies (content that can post anytime)
